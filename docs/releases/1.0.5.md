# Release 1.0.5

The default profile store moves from
`%kernel.project_dir%/var/cache/%kernel.environment%/profiler` to
`%kernel.cache_dir%/profiler`. The kernel cache directory follows
`APP_CACHE_DIR`, so projects mounted on filesystems that cannot enforce private
Unix modes (for example NTFS bind mounts under DDEV) can keep profiles on a
private cache volume instead of failing admin requests with "Profiler storage
permissions could not be restricted".

The storage boundary is unchanged: the directory stays `0700`, profiles and
indexes stay `0600`, and unsafe links or permissions are still rejected.
Projects that set `profiler.storage_dir` keep their configured path, because
project configuration still loads after bundle defaults. Profiles under the
previous default location are ephemeral and are not migrated; they can be
deleted with the old cache directory.

Validation: complete PHPCS/PHPStan/PHPUnit QA (39 tests, 810 assertions)
including a regression for the kernel cache default, and the Twig stopwatch
integration fixture against a real consumer autoloader.
